# Lily & Light Counselling Website

Static GitHub Pages website for Lily & Light.

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — mobile navigation and WhatsApp enquiry form
- `jenefa.jpg` — updated supplied profile photo
- `logo.png` — original website logo (unchanged)
- `favicon.svg` — browser icon
- `privacy.html` — privacy information
- `disclaimer.html` — website disclaimer
- `robots.txt` / `sitemap.xml` — search-engine files

## Publish on GitHub Pages
Upload all files to the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

The current sitemap assumes:
`https://lilylighttherapy.github.io/Lilylighttherapy/`

If the repository name or domain changes, update `sitemap.xml` and `robots.txt`.

## Before going live
Review all professional, pricing, service, privacy and emergency-information wording with the practice owner. Replace testimonial placeholders only with testimonials that the practice has permission to publish.
